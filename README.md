# Cloud-Practical
### 3.2 Platform as a Service (PaaS)
*   **Description:** Supplies an on-demand environment for developing, testing, delivering, and managing software applications, abstracting away the underlying infrastructure.
*   **User Responsibility:** Application code, business logic, and data configurations.
*   **Provider Responsibility:** Operating systems, databases, runtime environments, servers, and storage infrastructure.
*   **Examples:** Heroku, Google App Engine, AWS Elastic Beanstalk.
